# JAINAM Portfolio Launch Teaser — Production Blueprint

## Purpose and format

This is a **15-second vertical 9:16 Instagram Story** designed to make viewers curious about Jainam’s work and then reveal the Signal Edition portfolio. It uses the existing black, white, charcoal, and ember UI language, current portfolio screens as the product reference, and no public URL in the final frame.

## Phase 2 — Global definitions

| Element | Definition |
|---|---|
| Visual sub-genre | Premium science-fiction thriller teaser with editorial product-film restraint |
| Rendering and line | Photorealistic black-glass device, precise interface reflections, thin ember rules, controlled grain |
| Lighting and colour | Obsidian black, soft white, deep charcoal, Signal Ember accents, low-key volumetric light |
| Detail density | Minimal environment; high-detail interface fragments and screen reflections |
| Recurring object | A vertical black-glass portfolio display carrying Jainam’s real Signal Edition visual language: JAINAM wordmark, ember J mark, chrome sculptural hero, project cards, and editorial labels |
| Text and language | On-screen English text only; no voiceover |
| BGM source | Separate original cinematic sound design; no copyrighted composition or imitation |
